Portfólio pessoal desenvolvido com foco em identidade visual vintage e narrativa visual, apresentando minha trajetória, experiências, projetos e formação na área de tecnologia e dados.

---

## Sobre o Projeto

O projeto foi desenvolvido utilizando apenas HTML, CSS e JavaScript, buscando criar uma experiência visual inspirada em pergaminhos, arquivos antigos e manuscritos.

A proposta foi transformar um portfólio tradicional em algo mais imersivo e autoral, combinando estética vintage com design moderno.

---

## Funcionalidades

- Layout responsivo
- Navegação com scroll suave
- Animações de entrada (reveal)
- Menu mobile
- Timeline acadêmica
- Seção de projetos
- Cards de certificados
- Formulário de contato integrado
- Identidade visual personalizada

## Objetivo

O principal objetivo do projeto foi praticar:

- Estruturação de interfaces modernas
- Organização de layout responsivo
- Design visual e identidade própria
- Experiência do usuário
- Desenvolvimento front-end sem frameworks
